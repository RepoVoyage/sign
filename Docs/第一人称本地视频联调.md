# 第一人称本地视频联调

此入口只测试已部署的逐词 CV 服务，不连接 GO 3S，不进入连续翻译、字幕或 TTS 管线。

1. 在设置页选择“模型 B（第一视角）”。将一个只包含单个完整手语词的 MP4 放到手机文件目录；例如用 `adb push 你1.MP4 /sdcard/Download/`。
2. 保持手机可以访问互联网，先不要连接相机。主界面“第一人称 · 本地视频测试”填写 **CV 服务令牌**，点击“选择 MP4 并识别”。令牌只保留在当前界面的内存中，不是 LLM 密钥或服务器登录密码。
3. 在文件选择器中选该 MP4。App 把最多 32 MiB 的原始文件字节作为 `video/mp4` 请求体发送至 `POST https://101.37.234.129/v1/recognize`，显示状态、检测到手的帧比例和最多三个候选词。

`OK` 表示返回了候选，仍需人工核对。`TOO_SHORT` 或 `INSUFFICIENT_HAND_DETECTION` 表示此片段不能用于补句，应重拍。`CV HTTP 401` 检查 CV 令牌；`413` 检查文件大小；`415` 检查文件是否由接口按原始 MP4 上传。本入口不调用 `/v1/compose-signs`，也不自动播报。

当前 App 的 production 连续识别源仍未接入；“开始翻译”按钮的可用性与本地视频入口无关。连接 GO 3S 后进程可能绑定无公网的相机 Wi-Fi，此测试入口暂要求先断开相机。相机在线时经蜂窝上传以及连续动作分段留到下一轮联调。
