# 第一人称本地视频联调

此入口按顺序测试已部署的逐词 CV 服务和五句补全 Agent，不连接 GO 3S，不进入连续翻译、字幕或 TTS 管线。

1. 在设置页选择“模型 B（第一视角）”。将若干个**每段只含一个完整手语词**的 MP4 放到手机文件目录；例如“我”“回”“家”各一段，可用 `adb push 我1.MP4 /sdcard/Download/` 传入手机。
2. 保持手机可以访问互联网，先不要连接相机。主界面“第一人称 · 本地视频测试”分别填写 **CV 服务令牌**和 **Agent 服务令牌**。两者不同，也都不是 LLM 密钥或服务器登录密码；令牌只保留在当前界面的内存中。
3. 按手语动作顺序反复点击“选择并识别下一个词”，逐段选择 MP4。App 把每段最多 32 MiB 的原始文件字节作为 `video/mp4` 请求体发送至 `POST https://101.37.234.129/v1/recognize`，显示每段状态、帧数、检测到手的帧比例和最多三个候选词。最多收集 12 段。
4. 确认顺序后点击“完成本句并补全”。App 把每段 `OK` 响应的 `candidates` 按顺序放进 `gestures`，发送 JSON 到 `POST https://101.37.234.129/v1/compose-signs`；界面显示 `status`、`sentence`、`alternatives`、`segmentId`、`revision`、`needsConfirmation`。例如“我”“回”“家”可能补成“我想回家”。要开始另一句，点击“清空重来”。

`OK` 表示返回了候选，仍需人工核对。`TOO_SHORT` 或 `INSUFFICIENT_HAND_DETECTION` 不会加入本句，应重拍。`CV HTTP 401` 检查 CV 令牌；`413` 检查文件大小；`415` 检查文件是否按原始 MP4 上传。`Agent HTTP 401` 检查 Agent 令牌；`504 MODEL_TIMEOUT` 表示云端补全超过期限。补句仅能从当前五句语料中选择，也可能返回 null。`needsConfirmation=true` 时不得自动播报。

当前 App 的 production 连续识别源仍未接入；“开始翻译”按钮的可用性与本地视频入口无关。连接 GO 3S 后进程可能绑定无公网的相机 Wi-Fi，此测试入口暂要求先断开相机。相机在线时经蜂窝上传以及连续动作分段留到下一轮联调。
