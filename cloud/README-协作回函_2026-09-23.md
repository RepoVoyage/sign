## 2. 需贵方确认的四个实现假设

1. **NAL 长度前缀 = 4 字节 avcc**（`length-prefixed-au` 未注明字节数）；若为 3 字节或 Annex-B 请告知。
2. **CSD 作为独立 AU 首送**（flags bit1，payload=61B SPS/PPS）；我方设为 decoder extradata 后不解码该 AU。
3. **draft ≥2Hz 的实现**：每 0.5s 一次部分识别（当前缓冲最近邻整句候选，boundary=UNCERTAIN）；
   段关闭时发终事件（RELIABLE/UNCERTAIN 按 margin）。draftText 为**整句候选**而非词累积草稿——
   请确认 App `SentenceManager` 按整句修订消费无碍。
4. **model-b（第一视角）**：无训练数据，SESSION_INIT 即回 `ERROR MODEL_NOT_READY`，不伪造。
