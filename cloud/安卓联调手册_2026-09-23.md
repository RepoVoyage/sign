# 安卓联调手册（v0，2026-09-23）

对象：安卓 App 开发同事。目标：把 GO 3S 拍摄流接入识别服务，拿到词流/句子事件。
识别侧能力与数字见 `实时识别与安卓适配构思_2026-09-23.md`；本手册只讲接口与部署。

## 1. 架构与分工

```
GO 3S ──WiFi/USB──> Android App ──HTTP JPEG帧──> 识别服务(本仓库) ──词流JSON──> App
                   App 负责：取流、降采样@10fps、JPEG q85、渲染事件、提示重打、TTS
                   服务负责：pose、停顿分割、整句识别、词边界、置信 margin
                   云 LLM：App 拿 sentence_candidate/stream 调百炼还原自然句（prompt 见
                           research/models/smoke/llm_restore_20260923/restore_eval.py CLOSED）
```

## 3. 接口契约

| 方法/路径 | 请求 | 响应 |
| --- | --- | --- |
| POST `/v1/sign/frame` | `{"session_id","ts","jpeg_b64"[,"flush":true]}` | `{"events":[...]}` |
| POST `/v1/sign/reset` | `{"session_id"}` | `{"ok":true}` |
| GET `/v1/sign/health` | — | `{"ok","model","long_edge","templates","sentences"}` |

- `ts`：会话内单调秒（用相机帧时间戳或 App 时钟，间隔 ≈0.1s）。
- 事件（`events` 非空即处理）：
```json
{"sentence_candidate": "请问厕所在哪里", "confidence_margin": 0.21,
 "low_confidence": false, "needs_repeat": false,
 "stream": [{"word": "请问", "start": 0.25, "end": 1.68}, ...],
 "seg_start": 12.3, "seg_end": 16.1}
```
- `needs_repeat=true`（margin<0.03，离线评估约 6% 请求）：**提示用户重打，不要播 TTS**。
- `stream` 里 `word="待确认动作"` = 看到动作但词义未知（现仅 1 处：生日快乐起手式）。
- 事件在停顿（腕速静止 ≥0.4s）时产出；App 可在用户停止打手势 ~0.5s 内收到。
- 一段打完想强制收尾：最后一帧带 `"flush": true`。

## 5. 延迟实测（开发机 RTX 4060 Laptop）

| 环节 | 数字 | 备注 |
| --- | --- | --- |
| pose wholebody GPU @640px | 75.6 ms/帧（13.2 fps） | cuDNN9 修复后实测（RTX 4060 Laptop） |
| pose wholebody GPU @1080px | 64.2 ms/帧（15.6 fps） | 同上；**服务默认档** |
| pose wholebody CPU @640px | 5.7 s/帧 | cuDNN9 缺失时的回退代价，警示用 |
| 分割+识别（DTW） | 实时率 2.8x | `continuous_stream.py` 模拟连续流，不含 pose |
| LLM 闭集还原 | ~1–3 s/句 | 百炼 qwen3.8-max，含 thinking |

预算结论：10fps 推帧时 pose 占 64–76 ms/帧 < 100 ms 帧间隔，**单机 GPU 可实时**；整链路 <2s/句成立。

**合并验收（2026-09-23，本机服务实测）**：17 句各 1 段经 `client_example.py` 推帧，
`sentence_candidate` 17/17 正确（逐条见 `smoke/wordstream_baseline_20260923/service_acceptance_20260923.json`）；
其中"别害怕有我在"margin=0.015 <0.03，生产会返回 needs_repeat=true 提示重打（预测本身正确，属预期行为）。

## 6. 扩句流程（新句子入库）

1. 按 `数据收集矩阵_2026-09-23.md` 录制（≥2 签者 ×2 环境，带 person_id/scene_id）。
2. 词级标注：用户给词义 + 10fps 目视边界（流程见 progress.md 2026-09-23 各条）。
3. 抽 pose 缓存（annotation_candidates 管线同格式 npz）→ 更新 manifest 与 `标注_粗标数据.json`。
4. 重启服务（模板库启动时加载）。
